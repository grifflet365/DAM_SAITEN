# Cyber header background

`cyber-space.webp` is an original background generated with the built-in ImageGen tool for this dashboard, based on the cyber-space header concept approved in this chat. No title or statistics are baked into the image; those are rendered as HTML from the dashboard data.

Generation prompt:

> Create a clean textless background plate matching the approved karaoke header: immersive deep navy cyberspace, cyan and electric violet fiber-optic streams, a perspective grid, large holographic audio-analysis rings on the right, floating equalizer panels and an audio waveform. Keep the middle-left dark enough for an HTML heading while preserving rich details above and below. Remove all lettering, numbers, title frames and status badges. Full-bleed wide composition, no people, logos or watermarks.

The generated PNG was converted to a 1440 × 576 WebP at quality 85 (185,382 bytes). The source PNG remains in the chat's generated-image library.

Animations are CSS overlays, can be paused with the header's 「演出」 button, and are disabled when the device requests reduced motion.
